# Full Stack Development Assignment

Lab tasks 1 to 13.

## Frontend (Tasks 1 - 7)
Open `index.html` directly in any browser:
- 01-concentric-circles
- 02-ten-horizontal-cards
- 03-todo-list
- 04-chessboard-js
- 05-snake-ladder-game
- 06-random-jokes-api
- 07-universities-by-country-api

## Node / Express (Tasks 8 - 12)
Inside each folder, run:
```
npm install
npm start
```
- 08-express-routes-template-engine (port 3000)
- 09-express-restful-crud-products (port 3000)
- 10-express-api-csr-products (port 3000)
- 11-express-mongodb-crud-products (port 3000, needs MongoDB running)
- 12-ecommerce-app (port 5000)

## React (Task 13)
Inside `13-react-portfolio`:
```
npm install
npm run dev
```
